# Colors

## Core Tokens

| Token | Value | Usage |
| --- | --- | --- |
| `--scx-blue` | `#2563eb` | Primary actions |
| `--scx-purple` | `#7c3aed` | Gradient end |
| `--scx-cyan` | `#06b6d4` | Online and signal accents |
| `--scx-charcoal` | `#101217` | Dark background |
| `--scx-panel` | `#171a21` | Dark cards |
| `--scx-surface` | `#ffffff` | Light cards |
| `--scx-success` | `#16a34a` | Success |
| `--scx-warning` | `#d97706` | Warning |
| `--scx-error` | `#dc2626` | Error |

## Primary Gradient

```css
linear-gradient(135deg, #2563eb 0%, #7c3aed 100%)
```
