# Components

## Primary Components

- App shell with sidebar and top status bar.
- Status card.
- Device list row.
- Device detail panel.
- Telemetry chart panel.
- Command panel.
- Provisioning stepper.
- Firmware update progress.
- Toast notification.
- Empty state.
- Error alert.

## Component Rules

- Cards use 8px radius unless platform defaults require another value.
- Avoid nested cards.
- Use icons for tool actions.
- Keep status color and text paired for accessibility.
