# Dark Mode

Dark mode uses charcoal backgrounds, elevated panels, and blue-purple accents.

## Tokens

- Background: `#101217`
- Panel: `#171a21`
- Panel border: `#2a2f3a`
- Text: `#f8fafc`
- Muted text: `#a8b3c7`

Avoid making the UI a single dark-blue palette; use cyan, green, amber, and neutral contrast for state.
