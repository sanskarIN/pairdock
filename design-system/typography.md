# Typography

## Font Stack

Use a modern sans-serif stack:

```css
font-family: Inter, Segoe UI, Roboto, Helvetica Neue, Arial, sans-serif;
```

## Scale

- Display: 40px / 48px / 700
- Page title: 28px / 36px / 700
- Section title: 20px / 28px / 650
- Body: 16px / 24px / 400
- Label: 13px / 18px / 600
- Caption: 12px / 16px / 500
