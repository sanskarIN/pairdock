# Contribution Guide

Contributions should preserve the architecture and branding:

- PairDock
- Pair, provision, monitor, and update Wi-Fi and Bluetooth devices.
- Made by Sanskar

## Add A Module

1. Create domain-specific source files.
2. Add interfaces at boundaries.
3. Add tests or test docs.
4. Update docs and examples.
5. Mark future work with `SCX-TODO:`.
