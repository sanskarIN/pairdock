# Deployment Guide

## Environments

- Local: Docker Compose and local secrets.
- Staging: deployed backend, dashboard, database, and device simulator.
- Production: hardened infrastructure with managed database, TLS, monitoring, alerting, and release approvals.

## Deployment Units

- Backend API container.
- Worker container.
- Web dashboard container.
- Firmware package artifacts.
- Database migrations.
