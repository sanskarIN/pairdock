# Desktop App Guide

The desktop app is a C# MVVM-style device operations console.

## Screens

- Dashboard
- Device list
- Device detail
- Wi-Fi setup
- Bluetooth pairing
- Live telemetry
- Logs
- Firmware update
- Settings
- About

## Branding

The About page and shell footer show:

```text
PairDock
Pair, provision, monitor, and update Wi-Fi and Bluetooth devices.
Made by Sanskar
```

## Design

The desktop UX uses a premium SaaS dashboard feel with a sidebar, top status bar, rounded cards, dark/light themes, badges, signal indicators, and keyboard-friendly navigation.
