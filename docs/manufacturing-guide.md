# Manufacturing Guide

Manufacturing assets live in `manufacturing/`.

## Station Flow

1. Flash bootloader and application firmware.
2. Assign serial number and hardware revision.
3. Calibrate sensors.
4. Run GPIO, UART, SPI, I2C, ADC, PWM, Wi-Fi, and BLE tests.
5. Provision device certificate.
6. Record quality checklist.
7. Package device with label and documentation.
