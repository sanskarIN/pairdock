# Mobile App Guide

The mobile app is a .NET MAUI-style companion app focused on provisioning and device control.

## Flows

- Onboarding
- Login and registration
- Bluetooth pairing wizard
- Wi-Fi provisioning wizard
- Device dashboard
- Telemetry
- Commands
- Firmware update status
- Settings and About

## Offline Mode

The app includes an offline queue service concept for commands and provisioning logs.
