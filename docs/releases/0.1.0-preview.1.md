# PairDock 0.1.0-preview.1

Made by Sanskar. Released as a developer preview, not a stable production release.

## Included

- ASP.NET Core API, Clean Architecture layers, in-memory EF Core implementation, and authentication foundation.
- C# protocol contracts and `PairDock.Sdk` NuGet package.
- Host-buildable C/C++ firmware core and two CTest targets.
- Blazor dashboard and Windows desktop application; mobile app is a MAUI-style scaffold.
- Device simulator, SQL reference schema, CI, security and manufacturing documentation.

## Assets

- `PairDock.Sdk.0.1.0-preview.1.nupkg`: preview C# SDK, targeting .NET 8.
- `pairdock-device-simulator-0.1.0-preview.1-win-x64.zip`: framework-dependent Windows simulator build; requires .NET 8 runtime.
- `pairdock-protocol-0.1.0-preview.1.zip`: protocol contracts, examples, and binary packet notes.
- `SHA256SUMS.txt`: SHA-256 checksums for the three downloadable assets.

## Verification

The API, dashboard, SDK, and Windows desktop ViewModel tests build locally. API, application, infrastructure, protocol, SDK, desktop, and two firmware host tests pass. GitHub CI is the cross-machine verification gate; check its status on the release commit.

## Known Limitations

- API data is in memory; the PostgreSQL schema is not wired to EF Core runtime persistence.
- Device ownership checks and per-device telemetry credentials are incomplete.
- BLE, Wi-Fi, secure boot, and OTA still require ESP-IDF adapters and hardware validation.
- Several dashboard/mobile/tool flows remain scaffolds or examples.
- Do not expose the API to untrusted networks or use it for safety-critical control.

The first stable release should follow persistent storage, device authorization, signed OTA, integration tests, and real-hardware verification. The source remains available under the MIT License.
