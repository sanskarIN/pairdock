# UI/UX Design Guide

PairDock uses a premium modern SaaS dashboard direction.

## Visual System

- Primary gradient: blue to purple.
- Dark background: charcoal near black.
- Accents: cyan, blue, purple.
- Success: green.
- Warning: amber.
- Error: red.
- Cards: rounded corners.
- Typography: modern sans-serif.
- Layout: clean dashboard, strong hierarchy, responsive.

## UX Principles

- Make device state visible.
- Make pairing and provisioning feel guided.
- Keep admin workflows efficient.
- Use clear empty states and loading states.
- Use friendly, specific errors.
- Keep keyboard navigation and accessible contrast.

See `design-system/`.
