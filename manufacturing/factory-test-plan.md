# Factory Test Plan

## Tests

- Boot validation.
- GPIO loopback.
- UART loopback.
- SPI peripheral detection.
- I2C sensor scan.
- ADC threshold sample.
- PWM output validation.
- Wi-Fi scan.
- BLE advertising.
- Button input.
- LED status.
- Secure storage check.
- Certificate presence.

Each device must pass before packaging.
