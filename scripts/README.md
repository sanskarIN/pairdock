# Scripts

Automation scripts for PairDock.

Made by Sanskar.

## Scripts

- `bootstrap.ps1` and `bootstrap.sh`: local setup checks.
- `build-all.ps1`: build core projects.
- `test-all.ps1`: run starter test projects.
- `format.ps1`: formatting hook placeholder.
- `lint.ps1`: lint/static check placeholder.
- `generate-version.ps1`: create version metadata.
- `new-module.ps1`: scaffold future modules consistently.
