# Hardware-In-Loop Testing

## Station Requirements

- USB serial connection.
- Programmable power supply.
- Wi-Fi test network.
- BLE-capable host.
- GPIO loopback fixture.
- Sensor fixture if available.

## Flow

1. Flash firmware.
2. Enter manufacturing mode.
3. Run factory tests.
4. Provision certificate.
5. Pair with app.
6. Provision Wi-Fi.
7. Send telemetry.
8. Execute OTA update.
